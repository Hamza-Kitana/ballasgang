# Ballas Purple Dynasty

موقع سينمائي لعصابة Ballas في FiveM — ثيم بنفسجي، تحميل، اضغط للدخول، وأقسام بدون سكرول للصفحة.

## المميزات

- شاشة تحميل ثم شاشة **Enter**
- خلفية سينمائية متحركة (+ فيديو إذا أضفت ملف)
- أعضاء · لايف · إنجازات · تقديم
- صفحة حساب لكل عضو `/members/:id`

## فيديو الخلفية (اختياري)

ضع ملف الفيديو هنا ليشتغل تلقائياً:

```
public/ballas-bg.mp4
```

بدون الملف، الخلفية المتحركة البنفسجية تشتغل لوحدها.

## التشغيل

```sh
bun install
bun run dev
```

أو:

```sh
npm i
npm run dev
```

ثم افتح `http://localhost:3000`.
